## 二、下单前「四点确认」

- [x] **① 主控 = STM32F411CEU6**（不能是 F401CCU6）→ **已确认**
- [ ] **② 触摸 IC = XPT2046**（下单页/客服确认；很多屏其实是 FT6236 / GT911）→ **待确认**
- [x] **③ 板载晶振 = 25MHz** → WeAct 黑药丸 = 25MHz（**到货看丝印复核：`25.000`**）
- [ ] **④ ESP8266 前作是否已有 / 传感器供电电压** → 见第三节

> 为什么主控不能买成 F401CCU6：只有 84MHz / 64KB RAM，**撑不起 96MHz + LVGL**，整个计划崩盘。

---

## 三、供电与复用注意（别踩）

- ⚡ **RS485 温湿度变送器通常要 12~24V DC 供电**（不是 3.3V/5V）。下单时确认供电范围，并准备对应电源（12V 适配器 / 可调电源）。**开发板只提供 RS485 的 A/B 信号线，不给传感器供电。**
- ♻️ **ESP8266-01S 若前作「环境监测项目」已买可直接复用**。注意它是 **3.3V 供电、AT 指令、TX/RX 电平 3.3V**。
- 🔌 ESP8266-01S 是 2×4 排针，接线见后续硬件笔记（W7 用）。

---

## 四、为什么这些「认准」很重要

- **晶振型号**直接决定 CubeMX 里 HSE 配置：25MHz → 96MHz 用 `PLLM=25 / PLLN=192 / PLLP=2 / PLLQ=4`（详见 vault 笔记 `03-CubeMX新建工程与时钟树.md`）。
- **传感器买成 I2C 版 SHT20** → 练不到 Modbus-RTU，W2 整周白做。
- **屏幕买成并口** → F411 引脚不够，驱动天上地下。
